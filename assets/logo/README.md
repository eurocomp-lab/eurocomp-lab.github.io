# Logo files

| File | Use |
|---|---|
| `eurocomp-lab-logo.svg` | Master logo as supplied by the designer, unchanged. For white or light backgrounds. |
| `eurocomp-lab-logo-white.svg` | Version for dark backgrounds, used in the blue navbar: white wordmark and outlines, original gold and cream fills, trimmed to the artwork. |
| `eurocomp-lab-mark.svg` | Symbol only, without the wordmark. For small spaces such as icons. |
| `favicon.png` | Browser tab icon (96 × 96 px), made from the symbol. |

The white version was derived from the master file for use on the navbar. If the
designer supplies an official version for dark backgrounds, replace
`eurocomp-lab-logo-white.svg` with it and keep the file name, so no config change
is needed.
